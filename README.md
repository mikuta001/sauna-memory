# Sauna Memory

サ活体験を記録し、年や季節ごとに思い出を振り返るWebアプリです。

訪れた施設・訪問日・感想・評価・同行者を記録できます。
蓄積した記録から訪問回数や初めて訪れた施設などを振り返ることができます。  
また、AIを使用したサ活の振り返りもできます。

## サービス概要

### サービスの目的

サウナでの体験を、そのときの感想や一緒に訪れた人とともに残し、
自分のサウナ活動を振り返れるようにすることを目指しています。

### 想定ユーザー

- 訪れたサウナや感想を記録したい人
- 同行者との思い出を残したい人
- 年や季節ごとに、自分のサウナ活動を振り返りたい人

### 機能一覧

| 分類 | 機能 | 内容 |
| --- | --- | --- |
| 認証 | ユーザー登録 | 名前・メールアドレス・パスワードで登録 |
| 認証 | ログイン・ログアウト | Supabase Authによる認証 |
| 記録 | 施設検索 | 登録済み施設を名前の部分一致で検索 |
| 記録 | 訪問記録の作成 | 施設・訪問日・感想・評価・同行者を保存 |
| 記録 | 訪問記録の一覧 | 自分の記録を訪問日の新しい順に表示 |
| 記録 | 訪問記録の編集・削除 | 保存した記録の変更・削除 |
| 振り返り | 期間指定 | 年・季節・全期間で絞り込み |
| 振り返り | 訪問回数 | 選択期間の回数を集計し、条件に応じて前年・前季節と比較 |
| 振り返り | 初訪問施設 | 選択期間に初めて訪れた施設を表示 |
| 振り返り | 高評価の記録 | 評価の高い訪問記録を最大3件表示 |
| 振り返り | 同行者の集計 | 最も一緒に訪れた回数が多い同行者を表示 |
| AI | 振り返りコメント | 選択期間の記録から日本語の短い振り返りを生成 |
| アカウント | 登録情報の変更 | 名前・メールアドレス・パスワードを変更 |

## 利用の流れ

1. ユーザー登録、またはログインする
2. 訪れたサウナ施設を検索・選択する
3. 訪問日・感想・評価・同行者を入力して保存する
4. ホーム画面で記録を確認・編集する
5. アルバム画面で期間を選び、集計やAIコメントを通して振り返る

## 外部API・サービス

### Supabase Auth

以下の認証・アカウント管理に使用しています。

- ユーザー登録
- ログイン・ログアウト
- 認証セッション管理
- メール確認
- メールアドレス・パスワード変更

### OpenAI Responses API

選択期間のサウナ訪問記録をもとに、
日本語の短い振り返りコメントを生成します。

生成時には、施設名・訪問日・評価・感想・同行者名などを含む
訪問記録をOpenAI APIへ送信します。
